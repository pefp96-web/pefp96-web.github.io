소방 서류 자동 작성기

2·3급 소방안전관리 대상 건물의 법정 서류를 건물 정보 한 번 입력으로 만듭니다. 회원가입 없이 브라우저에서 바로 만들고, 입력한 정보는 서버에 저장하지 않습니다.

작성기 바로 가기

만들 수 있는 서류

  • 소방계획서 (시행령 제27조 15개 항목, 자위소방대 자동 편성)
  • 소방안전관리 업무수행기록표 12개월치 (별지 제12호서식)
  • 자위소방대 및 초기대응체계 교육·훈련 실시 결과 기록부 (별지 제13호서식)
  • 소방훈련·교육 실시 결과 기록부 (별지 제28호서식)
  • 자체점검기록표 게시용 (별표 5)

건물 용도별 작성 예시

  • 아파트(공동주택) 소방계획서 예시와 세대점검 계획
  • 학원 건물 소방계획서 예시와 작성 방법
  • 숙박업소(모텔·호텔) 소방계획서 예시와 작성 방법
  • 요양원·요양시설 소방계획서 예시와 작성 방법
  • 어린이집 소방계획서 예시와 작성 방법
  • 공장 소방계획서 예시와 작성 방법
  • 상가 건물(근린생활시설) 소방계획서 예시와 작성 방법

서류별 작성 예시

  • 자위소방대 편성표 작성 예시
